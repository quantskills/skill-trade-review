# Review Checklist

## Data

- trade rows validated
- `status` and `direction` standardized
- mark price filled or warning recorded
- asset type identified

## Review

- summary complete
- attribution complete
- market review generated
- per-trade review generated
- patterns generated
- advice generated

## Delivery

- `result_json` valid
- warnings explicit
- LLM output, if enabled, does not mutate numeric fields
- `python scripts/test.py` passed
